# Salman Farsy — Portfolio

A responsive, single-page portfolio for Salman Farsy, built with semantic HTML, CSS, and a small amount of vanilla JavaScript. It includes responsive navigation, scroll-based section reveals, subtle motion, a featured project preview, and reduced-motion support.

## Run locally

No build step or package installation is needed. From this directory, run:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Then open `http://localhost:8000` in your browser.

## Files

- `index.html` — page content and structure
- `styles.css` — layout, responsive styling, and animations
- `script.js` — mobile menu, scroll reveals, and current year
- `favicon.svg` — site icon
